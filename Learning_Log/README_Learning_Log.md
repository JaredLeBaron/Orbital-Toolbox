\# Orbital Toolbox Learning Log



\## Purpose



This folder tracks my progress while building and understanding the Python orbital mechanics toolbox.



The goal is not only to write working code. The goal is to understand the math, physics, assumptions, limitations, and validation methods behind each feature.



This learning log is part of my aerospace engineering rebuild.



\---



\## What This Log Tracks



\- What I worked on each week

\- What I learned

\- What confused me

\- What mistakes I found

\- What equations I reviewed

\- What code I inspected or changed

\- What validation checks I performed

\- What I need to review next



\---



\## Weekly Files



Each week gets its own file:



\- `Week\_01.md`

\- `Week\_02.md`

\- `Week\_03.md`

\- `Week\_04.md`



Each weekly file should include:



\- Weekly goal

\- Project areas reviewed

\- Equations/concepts studied

\- Code reviewed or changed

\- Validation checks

\- Mistakes/confusions

\- Next actions



\---



\## Related Project Areas



\- `docs/` — project documentation

\- `tests/` — tests and validation-related code

\- `examples/` — usage examples

\- `scratch/` — temporary experiments and rough work

\## Rule



If I cannot explain a feature in words, equations, assumptions, and validation checks, I do not understand it well enough to rely on the code.
